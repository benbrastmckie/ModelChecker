# Phase 2 Handoff: Flip the convention to guard-first, in lockstep

**Status**: COMPLETED. Commit: `d6677e0c task 196 phase 2: flip the convention to guard-first, in lockstep`

## What changed

- `operators.py`: `UntilOperator`/`SinceOperator` `true_at`/`false_at` signatures are now
  `(self, guard_arg, event_arg, eval_point)`, positional identity against `Untl`/`Snce`'s
  `(guard, event)` fields. `DefNextOperator`/`DefPrevOperator` derivations are now
  `[UntilOperator, [BotOperator], argument]` / `[SinceOperator, [BotOperator], argument]`
  (guard=bot first, event=argument second). Docstrings rewritten to state guard-first, with
  the retired Burgess-convention citation kept only as history.
- `semantic/formula.py`: `translate`'s `\Until`/`\Since` rules are positional identity
  (`guard_arg, event_arg = arguments`). Module docstring's swap section rewritten to record
  there is no longer a swap.
- `oracle/bimodal_logic/translation.py`: `_PRIMITIVE_BINARY`'s `untl`/`snce` tuples flipped to
  `("\\Until", "guard", "event")` / `("\\Since", "guard", "event")`.
- Every order-bearing formula string was swapped in lockstep (operands reordered so each
  string still denotes the same proposition), verified with a parse/swap/infix round-trip tool
  built on the codebase's own `model_checker.utils.parse_expression` + a renderer mirroring
  `Sentence.infix()` exactly (source: `/tmp/.../scratchpad/swap_lib.py`, not persisted to the
  repo) -- every output was also inspected by hand against the occurrence's own comment/meaning:
  - `examples.py`: 16 BX axiom conclusion strings (BX2G/BX2H/BX3/BX3P/BX5/BX5P/BX6/BX6P/BX7/BX7P/
    BX10/BX10P/BX12/BX12P/BX13/BX13P), plus the `Using binary infix:`/`# Formula:` comments and
    the historical PAPER-AXIOM AUDIT block (superseded-note added, history preserved).
  - Bimodal tests: `test_until_since_integration.py` (5 occurrences + docstrings),
    `test_next_prev.py` (derived-definition structure tests + 2 equivalence formulas),
    `test_operators.py` (2 mirror-translate tests, renamed to "positional_identity"),
    `test_structure.py` (`prior_UZ` A0 frame-class instance), `test_certificate_a2_triangle.py`
    (3 occurrences of a generic box-free Until conclusion -- confirmed order-insensitive at that
    specific closure-size/enumeration-count model point, since p/q are otherwise symmetric, but
    swapped anyway for convention consistency; re-verified still green after the swap).
  - `test_formula.py`: `TestTranslateUntilSinceOrderSensitive` rewritten from a swap assertion to
    a positional-identity assertion (renamed methods); `test_box_of_until_of_atoms` expected
    value updated; `_eval_mc_ast`'s until/since clauses flipped to `guard, event = ast[1], ast[2]`.
  - `test_certificate_fixtures.py`: internal `("untl"/"snce", event, guard)` tuple flipped to
    `(tag, guard, event)` throughout (`parse_formula`, `coherent_at`, `fulfil_at`) -- chose the
    flip branch, not the fallback; `expected_verdicts.json` confirmed unchanged.
  - `oracle/bimodal_logic/tests/test_json_translation.py`: 7 failing sites fixed (json_to_prefix
    order assertions + the next/prev equivalence formulas run through real ModelChecker
    semantics).
