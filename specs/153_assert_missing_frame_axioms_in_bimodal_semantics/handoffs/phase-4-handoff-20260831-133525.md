# Phase 4 Handoff: Implement and wire the two Skolemized constraints

**Status**: COMPLETED (with a recorded deviation — see below)

## What was done

- Added `build_seriality_constraint` and `build_interpolation_constraint` to `core.py`,
  immediately after `build_forward_comp_constraint`, matching the Skolemized encoding the
  research report validated. Both docstrings follow house style (axiom statement, ProofChecker
  Alignment paragraph, Returns block). Neither contains `z3.Exists`.
- Wired both into `build_frame_constraints`'s returned list, after `forward_comp` and before
  `*skolem_abundance`, preserving the documented MBQI-ordering rationale.
- Phase 3's two test files (`test_frame_constraints.py`, `test_frame_class_mapping.py`) are fully
  GREEN: 27/27 passed in 18.77s. One test-design issue was found and fixed along the way: the
  `TestInterpolation` positive/negative tests needed M=3 to get a non-trivial duration
  decomposition within `is_valid_duration`'s guard; the naive M=3 fixture hit a **pre-existing**
  MBQI pathology in `capped_skolem_abundance_constraint` when checking bare frame-constraint
  satisfiability with no ground terms (confirmed present in the pre-Phase-4 tree too, via a
  git-blob reconstruction at commit `b7bc19c3`) — fixed by adding `temporal_depth=0` to that
  fixture (a real, pre-existing settings option that skips the abundance constraint), not by
  raising any timeout.

## Deviation: BM_CM_4 cost regression (recorded, not resolved here)

Running the full bimodal unit suite surfaced a genuine, fully-characterized regression:
`BM_CM_4` (N=2, M=2 countermodel example) goes from 4.07s decided `match` (pre-Phase-4) to
`inconclusive` at its own 120s `max_time` with both new axioms present.

| Variant | check_result | solving_time |
|---|---|---|
| neither | match | 3.10s |
| seriality_only | match | 9.27s |
| interpolation_only | match | 6.33s |
| both | inconclusive | 40.21s (probe budget); 120.37s at full budget |

Neither axiom alone is responsible; the cost is superlinear in their combination (working
hypothesis: cross-instantiation between the two new Skolem witness functions under MBQI). One
mitigation (explicit pattern anchoring Interpolation to its premise's ground term) was tried and
did not recover a decided result. This is a cost regression (`inconclusive`, not a decided
`unsat`) — not shown to be a soundness/verdict flip.

Per this plan's own rollback section, the anticipated safe fallback for "a regression traceable to
the new axioms and no encoding change recovers it" is to land Seriality alone and defer
Interpolation to a follow-on task. **Not applied unilaterally** — it would silently narrow this
task's shipped scope (both axioms asserted) without the user's decision, so both axioms remain in
the implementation as specified. This is the central open item Phase 7 and the summary carry
forward.
