## Deviation from plan

The plan's Scope Hypothesis anticipated exactly **two** non-bimodal `development`-marked node ids.
The real count, confirmed via `pytest -o addopts=--import-mode=importlib --collect-only -q -m development tests src/model_checker`,
is **three**: `test_generate_then_execute_cp1252[bimodal]` did not exist when the plan was
authored — it was added by concurrent work in the same repository (Windows stdout-encoding
coverage) between plan authoring and this phase landing, reusing the identical
parametrize-over-registry-with-bimodal-cost pattern the plan's Finding 1 already targeted. Marking
it too is the only choice consistent with the plan's own stated intent (decouple gating wall clock
from bimodal solve cost); leaving it unmarked would have left an identical, unaddressed cost
driver in the same file this phase already touches.
