## Two things worth carrying forward

1. **A `pytest_collection_modifyitems` hook sees the WHOLE session's items**, not just its own
   directory's. The first version of the hook had no path check and marked all 2534 tests in the
   repo; the gating expression then collected zero. Per-root containment checks cannot see this
   (they never load the theory's conftest) -- only a mixed-root collection can.
2. **This task's axioms caused a gating failure outside the bimodal test tree.**
   `tests/cli/conftest.py`'s tiny example used bimodal with no explicit `max_time`. Measured:
   ~0.42s pre-axiom, ~4.2-4.7s with both axioms, so it now always times out at the inherited 1s
   budget. Fixed by switching that fixture to logos. This is an independent ~10x cost data point
   on a far simpler example than BM_CM_4.
