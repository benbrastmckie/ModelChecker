## Key Decisions Made

- **Extraction reads `registry.target_window()` once per lasso and splits it into
  back/mid/fwd by position, not by re-deriving slot indices.** `target_window()` already
  enumerates exactly one representative position per slot in ascending order
  (`range(-nb, nm+nf)`), which is *definitionally* back-then-mid-then-fwd order (`t` from
  `-nb` to `-1`, then `0` to `nm-1`, then `nm` to `nm+nf-1`) -- so `labels[:nb]`,
  `labels[nb:nb+nm]`, `labels[nb+nm:]` is correct by construction, no `wrap()` arithmetic
  needed on the extraction side.
- **`inject_z3_model_values` reuses the original semantics' Z3 `BoolRef` objects verbatim**
  rather than reconstructing equivalent ones against `self`. A label-bit/guess/selector
  variable's Z3 name depends only on `(lasso, slot, formula)` or `(formula)` or `(position)` --
  never on which `BimodalSemantics` instance built it -- so reconstruction would be pure
  overhead. Not yet exercised by a live iteration (Phase 15 wires that in); flag if Phase 15
  finds this assumption wrong for some reason not visible from Phase 10 alone.
- **Box guess extraction reads every boxed closure member's guess unconditionally**
  (`bx[formula.child] = ...` for every `Box` in `closure`), not only the ones with an
  allocated witness lasso -- matches `certificate.py`'s `WitnessFamily.bx_of` sparse-default
  design and keeps the exported `bx` complete rather than minimal.

## What NOT to Try

- Do not try to make `extract_certificate` work before `finalize_certificate()` has run --
  `registry.closure` is empty until then, so extraction would silently produce an empty
  family. This is not guarded defensively on purpose: calling extraction out of order is a
  caller bug the phase 12 structure hook must not make, not a case to paper over here.
- Do not reconstruct `inject_z3_model_values`'s constraints via `self.witness_registry.bit(...)`
  instead of reusing `original_semantics`'s own `BoolRef` objects -- see "Key Decisions Made"
  above for why that would be pure overhead, not a correctness fix.
