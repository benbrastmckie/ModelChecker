## Key Decisions Made

- **Fixed the two pre-existing cross-theory failures immediately rather than deferring them.**
  Neither was in Phase 19's (or any later phase's) file list, but both were one-line, low-risk,
  and would otherwise sit as unattributed "pre-existing" failures for whichever later phase's own
  full-repo check happened to notice them next -- likely Phase 24's "final verification," where
  they would look like a regression from THAT phase's own (unrelated) changes if not already
  fixed and documented.
- **`UNSTABLE_EXAMPLES` removal was justified structurally, not just empirically.** The plan's
  own task said "remove BM_CM_1's marking if the redesign collapses its tail" -- confirmed the
  redesign does more than collapse the tail: the root-cause functions
  (`build_seriality_constraint`, `build_interpolation_constraint`, `ForAllTime`, `ExistsTime`) no
  longer exist anywhere in `semantic/core.py` at all (confirmed by grep), so the entry criteria's
  heavy-tailed-Z3-heuristic root cause cannot recur by construction. The 20-consecutive-run
  empirical check is corroborating evidence, not the primary argument.
- **Lowered every above-floor `max_time` to 10s**, not just the ten Phase 17 already touched.
  Phase 19's own task ("confirm no test needs a max_time above the floor for solver reasons")
  reads as requiring the audit be exhaustive across all 53 examples, not just the previously
  excluded ones.
