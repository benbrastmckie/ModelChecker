## What Was Built

`specs/144_fix_oracle_per_formula_solve_timeouts/bench_solve_cost.py` -- a standalone harness that
drives `BimodalSemantics`/`ModelConstraints`/`BimodalStructure` directly (the same pipeline
`Z3OracleProvider.find_countermodel` uses), bypassing pytest so `smt.random_seed`/`sat.random_seed`
are controllable per run. Seeds are pinned via `z3.set_param(...)` in the harness only --
`code/src/model_checker/solver/z3_adapter.py` was not touched.

Supports `--formula {and_box_next,and_all_future_neg,all_sat_task_relation_ternary,all}`,
`--seeds`, `--repeats-at-seed0`, `--out <json>` with append/resume semantics (re-running skips
already-recorded (formula, seed, repeat_index) triples).
