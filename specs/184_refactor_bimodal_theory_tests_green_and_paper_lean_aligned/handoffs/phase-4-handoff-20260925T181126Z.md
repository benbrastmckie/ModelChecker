## Key Decisions Made

- `recheck`'s structural check covers labels-outside-closure and fresh-indexed atoms, but
  deliberately NOT bx-keys-outside-closure: `WitnessFamily.bx : Formula -> Bool` is a total,
  unrestricted Lean function, and `LocalCoherentLab`'s box clause only *applies* when `Box(chi)`
  is itself in the closure -- an unused `bx` entry is inert, not a precondition failure. This
  differs from the label case, where `LabelledLasso.label_sub` is a structural datatype
  invariant. See `TestRecheckStructuralFailure.test_bx_key_outside_the_closure_is_not_a_structural_violation`.
- Ported `Examples.lean`'s Lean-verified `posFamily` (report 02 section 3, T3) directly into
  `TestRecheckPositiveT3Fixture`, computed by hand from the Lean source's `occurs`/`once`/
  `phiPos`/`labBack`/`labMid`/`labFwd` definitions (not re-derived independently) -- this is the
  single highest-confidence positive test in the corpus, since its labels are taken verbatim
  from a source the Lean type-checker has already verified satisfies all four conditions.
- The two proved windows (`_coherence_window` = `[-2nb, nm+2nf)` for C1/C2,
  `_box_window` = `[-nb, nm+nf)` for C3) are separate functions, not one shared bound, matching
  D7's correction; `TestRecheckWindowDiscriminatorFixture` asserts the wide window strictly
  contains the narrow one and that the fixture's violation position (`-2`) is only reachable via
  the wide one.
- `recheck` never returns `"error"` -- that status belongs to a JSON-parsing boundary (missing
  `target`/`target.time` in raw wire input), which does not arise here since `target_time` is a
  required, already-typed Python parameter. Phase 5's round-trip wrapper (or a later JSON-facing
  entry point) is where `"error"` handling belongs.

  `Predicates.lean` exactly.
