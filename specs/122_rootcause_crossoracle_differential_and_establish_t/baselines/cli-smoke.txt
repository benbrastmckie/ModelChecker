=== python -m model_checker --help ===
usage: model-checker [options] [file_path]

            ModelChecker: Automated semantic theory validation and countermodel generation.
            Running without arguments starts interactive project creation mode.

positional arguments:
  file_path             Path to Python examples file to analyze

options:
  -h, --help            show this help message and exit

theory selection:
  Choose semantic frameworks

  --load_theory, -l THEORY
                        Load semantic theory: bimodal.

model constraints:
  Control proposition behavior

  --contingent, -c      Require all propositions to be neither necessary nor
                        impossible
  --non_null, -n        Require all propositions to have non-empty verifier
                        sets
  --non_empty, -e       Require all propositions to have non-empty subject
                        matter
  --disjoint, -d        Require propositions to have disjoint subject matters
  --maximize, -m        Compare multiple semantic theories on same examples

output control:
  Save and display options

  --save, -s [{markdown,json,jupyter} ...]
                        Save results. Formats: markdown, json, jupyter. No
                        args = all formats. With args = specified only
  --sequential, -q      Prompt to save each model individually (interactive
                        mode)
  --align_vertically, -a
                        Display temporal models vertically (top-to-bottom time
                        flow)

solver:
  SMT solver backend selection

  --z3                  Use Z3 solver (default)
  --cvc5                Use cvc5 solver (requires pip install cvc5)

debugging:
  Advanced analysis and troubleshooting

  --print_constraints, -p
                        Show internal solver constraints (for debugging)
  --print_z3, -z        Show raw Z3 solver output (very technical)
  --print_impossible, -i
                        Include impossible states in model display

utility:
  Version, upgrade, and help

  --version, -v         Show version and exit
  --upgrade, -u         Upgrade ModelChecker package

examples:
  model-checker                          # Interactive project creation
  model-checker examples.py             # Run examples file
  model-checker -l bimodal examples.py  # Use bimodal theory
  model-checker --save markdown         # Save output as markdown
  model-checker -c -n examples.py       # Force contingent, non-null propositions
