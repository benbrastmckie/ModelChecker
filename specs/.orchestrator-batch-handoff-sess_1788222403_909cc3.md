## Process lessons that cost real time here

- **A dispatch report is not termination.** `impl-176` reported `API Error: Connection lost
  mid-response`; `ps` showed no pytest running; I concluded it was dead and dispatched a
  replacement. It was alive and kept working 90 more minutes. Two agents edited
  `bimodal/semantic/core.py` concurrently for ~10 minutes. **Always call `ListAgents` before
  re-dispatching**, never infer death from `ps` or from a failure notification.
- **Idle notifications arrive out of order.** Two `idle_notification`s arrived describing state
  already superseded. Always verify against the repo, never trust message ordering.
- **Instructions race with in-flight work.** I told the agent to escalate the Phase 6 decision; it
  had already done Phase 6, then reverted it on my instruction, *after* the user had approved
  keeping it — so it had to be re-applied. Cost three commits (`d6b0ea41`/`47e2dd52`/`4d84ab98`).
