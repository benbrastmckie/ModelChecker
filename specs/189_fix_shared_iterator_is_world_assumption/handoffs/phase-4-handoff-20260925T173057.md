## What was done

- **Phase 2** (`_pin_theory_specific_values`): guarded the `is_world`/`possible` loop in
  `iterate/models.py`; added the hook with a no-op default on `BaseModelIterator`; injected the
  owning iterator into `ModelBuilder` (`iterator=self`, defaulting to `None`); overrode the hook
  in `BimodalModelIterator` to pin certificate variables.
- **Phase 3** (`_build_exclusion_constraints` / `_build_stronger_constraint`): routed
  `iterate_generator`'s two live constraint call sites through polymorphic
  `BaseModelIterator` methods instead of directly through `ConstraintGenerator`; the
  stronger-constraint path composes (conjoins) rather than replaces, since logos's and
  imposition's own overrides are `BoolVal(True)` placeholders; `_create_difference_constraint`'s
  default now delegates to `ConstraintGenerator`'s generic implementation instead of raising.
- **Phase 4** (`_check_model_isomorphism`): added the hook (default: delegate to
  `IsomorphismChecker`); bimodal overrides it to unconditionally return `(False, None)`, since
  the shared graph representation is built from `z3_world_states`, which bimodal never
  populates, producing a false-positive-isomorphic empty-graph pair.
